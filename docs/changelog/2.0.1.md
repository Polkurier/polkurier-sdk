2.0.1
=====

A patch release. Nothing changes for code written against 2.0.0.

Compatibility
-------------

More versions of the dependencies are accepted, so the SDK installs beside more applications. It
works with each on every supported Symfony line (6.4, 7.4 and 8.x):

| Package | 2.0.0 | 2.0.1 |
|---------|-------|-------|
| [`guzzlehttp/guzzle`](https://github.com/guzzle/guzzle) | 7 | 7 or 8 |
| [`guzzlehttp/psr7`](https://github.com/guzzle/psr7) | through Guzzle | 2 or 3, now required directly |
| [`phpdocumentor/type-resolver`](https://github.com/phpDocumentor/TypeResolver) | 1 | 1 or 2 |
| [`phpstan/phpdoc-parser`](https://github.com/phpstan/phpdoc-parser) | 2 | 1.13 or later, or 2 |
| [`psr/cache`](https://www.php-fig.org/psr/psr-6/) | 3 | 1, 2 or 3 |
| [`psr/log`](https://www.php-fig.org/psr/psr-3/) | 2 or 3 | 1.1 or later, 2 or 3 |

`guzzlehttp/psr7` is now listed because the SDK uses it directly; before, it arrived only through
Guzzle.

Documentation
-------------

- [`AccountServiceInterface::getAccountInfo()`](../../src/Api/Service/AccountServiceInterface.php)
  and [`AccountInfoMessage::isNewRegulations()`](../../src/Response/Account/AccountInfoMessage.php)
  say that `is_new_regulations` is true in one response per version of the terms of service: the
  call that reports it marks the notice as shown. Read `is_regulations_accepted` to know whether the
  current terms are accepted.
- [`GetAccountInfoMessage`](../../src/Request/Account/GetAccountInfoMessage.php) is described by the
  field it carries.

The `User-Agent` header now names `polkurier-sdk/2.0.1`.
