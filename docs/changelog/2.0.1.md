2.0.1
=====

Fixed
-----

- With `symfony/property-info` 7.4, the items of a list of strings, numbers or booleans are now
  read the way Symfony 8.x already read them: an item of another type is converted or left out of
  the list, and the difference is recorded as [response drift](../serialization.md). The item type
  was read from
  [`Symfony\Component\PropertyInfo\PropertyTypeExtractorInterface::getType()`](https://github.com/symfony/symfony/blob/7.4/src/Symfony/Component/PropertyInfo/PropertyTypeExtractorInterface.php),
  which the interface declares from Symfony 8.0, rather than from the extractor, which has had it
  since 7.1. With `symfony/property-info` 6.4 those items read as the API sent them, as before.

Packaging
---------

- `composer.json` no longer declares a `version`. The release is the git tag, and the SDK reports
  it as `polkurier-sdk/<version>` in the `User-Agent`.
